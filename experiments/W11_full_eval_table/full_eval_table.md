## VQA-Acc convention

- **vitextvqa**: questions with > 1 gold answer = 0 → VQA-Acc identical to EM on every question: yes.
- **vivqa**: questions with > 1 gold answer = 0 → VQA-Acc identical to EM on every question: yes.

Both datasets provide a single gold answer per question, so the soft VQA accuracy min(#matches/3, 1) reduces to exact match; we report it for completeness and state this in the thesis.
