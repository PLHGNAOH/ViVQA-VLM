## 6. Nhiệm vụ 4 — Load baseline + zero-shot inference (SV1 chủ trì)

Load đúng baseline đã chốt và chạy thử **10–30 mẫu** (chưa phải full test set):

```python
# ví dụ khung, thay bằng model đã chọn (BLIP-2 / Florence-2 / Qwen2.5-VL)
from transformers import AutoProcessor, AutoModelForVision2Seq
import torch

model_id = "..."  # baseline đã chốt ở W3
processor = AutoProcessor.from_pretrained(model_id)
model = AutoModelForVision2Seq.from_pretrained(
    model_id,
    load_in_4bit=True,          # QLoRA-friendly nếu thiếu VRAM
    device_map="auto",
    torch_dtype=torch.float16,
)

# zero-shot 1 mẫu để xác nhận pipeline thông
inputs = processor(images=image, text=question, return_tensors="pt").to(model.device)
out = model.generate(**inputs, max_new_tokens=32)
print(processor.decode(out[0], skip_special_tokens=True))
```

Mục tiêu: xác nhận **pipeline ảnh → question → answer chạy thông**, không phải đo accuracy.
