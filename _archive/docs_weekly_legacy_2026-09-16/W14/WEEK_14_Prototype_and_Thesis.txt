## 4. Nhiệm vụ 1 — Prototype Web (SV4 chủ trì, SV1/SV3 hỗ trợ)

Yêu cầu chức năng bắt buộc:

* Upload một ảnh tiếng Việt.
* Nhập câu hỏi bằng tiếng Việt.
* Sinh câu trả lời ngôn ngữ tự nhiên (dùng bản cải tiến final).
* Trực quan hoá **confidence** của model.
* Khi liên quan: hiển thị **OCR text trích được** và/hoặc **evidence được retrieve** (RAG).

Kiến trúc gợi ý:

```text
[Web UI]  --upload ảnh + câu hỏi-->  [Backend]
                                        |-- OCR (PaddleOCR/VietOCR)  (nếu scene-text)
                                        |-- VLM + adapter (PEFT final)
                                        |-- (RAG retrieve nếu áp dụng)
                                        v
                              answer + confidence + OCR/evidence
```

* Backend: Python + PyTorch + HF Transformers + PEFT, load base model + adapter final.
* Runtime: Colab Pro/Premium hoặc GPU server trường (đúng ràng buộc môi trường).
* Ưu tiên chạy được và ổn định hơn giao diện cầu kỳ.

```python
# khung inference cho prototype
model = load_base_then_adapter("adapters/final")   # PEFT, không full model mới
def answer(image, question):
    ocr = run_ocr(image) if is_scene_text(question) else None
    prompt = build_prompt(question, ocr)            # OCR/evidence nếu có
    out = model.generate(...)
    return decode(out), get_confidence(out), ocr
```
