## 3. Nhiệm vụ 1 — Triển khai cải tiến chính (SV3 chủ trì)

### Nếu là LoRA/QLoRA

Dựng vòng train PEFT hoàn chỉnh trên train split cố định:

```python
from peft import LoraConfig, get_peft_model, prepare_model_for_kbit_training
from transformers import TrainingArguments, Trainer

model = prepare_model_for_kbit_training(base_model)   # cho QLoRA
model = get_peft_model(model, lora_config)

args = TrainingArguments(
    output_dir="adapters/W08_run1",
    per_device_train_batch_size=..., gradient_accumulation_steps=...,
    learning_rate=2e-4, num_train_epochs=1,      # bản đầu: ít epoch
    fp16=True, logging_steps=20, save_steps=..., seed=42,
)
# train, theo dõi loss giảm
```

Xác nhận: loss giảm, `print_trainable_parameters()` cho thấy % param train nhỏ, adapter
lưu được ra `adapters/`.

### Nếu là OCR-enhanced prompting

Tích hợp OCR text (từ pipeline W4) vào prompt:

```python
ocr_text = run_ocr(image)                       # PaddleOCR / VietOCR
prompt = f"Văn bản trong ảnh: {ocr_text}\nCâu hỏi: {question}\nTrả lời:"
```

### Nếu là RAG

Dựng index (ảnh/OCR/caption) và bước retrieve evidence trước khi hỏi VLM.

## 4. Nhiệm vụ 2 — Chạy end-to-end trên subset rồi mở rộng (SV3 + SV1)

* Chạy thử trên subset nhỏ trước để bắt lỗi (OOM, shape mismatch, tokenizer).
* Khi ổn, chạy trên tập train/val đầy đủ theo protocol.
* Với QLoRA: canh VRAM; nếu OOM → giảm batch, tăng gradient accumulation, hoặc hạ rank.

> Ràng buộc: tuyệt đối không chuyển sang full fine-tuning để "cho nhanh". Nếu không hội tụ,
> backup theo risk plan là chuyển hướng prompting — không phá ràng buộc PEFT.

---

## 5. Nhiệm vụ 3 — Log run đầy đủ (SV4 chủ trì)

Mỗi run cải tiến ghi vào `experiments/W08_*/`:

* config PEFT (rank, alpha, target_modules, quantization)
* learning rate, batch, epoch, seed
* hardware, VRAM peak
* training time, loss curve
* prompt template (với OCR/RAG)

Không có log = run không tồn tại về mặt reproducibility.

---

## 6. Nhiệm vụ 4 — Đo nhanh trên val (chưa phải kết quả chính)

Chạy metric EM/VQA-Acc/ANLS trên **validation split** để có tín hiệu sớm bản cải tiến có
nhích so với baseline hay không. Đây là số để định hướng tinh chỉnh W9, chưa phải số báo cáo.
