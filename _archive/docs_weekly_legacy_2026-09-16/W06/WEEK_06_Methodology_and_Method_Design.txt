## 4. Nhiệm vụ 2 — Thiết kế cấu hình PEFT (SV3 chủ trì)

Nếu chọn LoRA/QLoRA, chốt trước các siêu tham số (sẽ tinh chỉnh ở W8–W9):

```python
from peft import LoraConfig, get_peft_model

lora_config = LoraConfig(
    r=16,                       # rank
    lora_alpha=32,
    target_modules=[...],       # xác định đúng module của baseline
    lora_dropout=0.05,
    bias="none",
    task_type="...",            # theo kiến trúc VLM
)
model = get_peft_model(base_model, lora_config)
model.print_trainable_parameters()   # xác nhận % param train rất nhỏ
```

Ghi rõ: quantization (4/8-bit), rank r, target_modules, learning rate, batch size, epoch dự kiến.
`print_trainable_parameters()` là bằng chứng "parameter-efficient" — đưa vào methodology.

## 5. Nhiệm vụ 3 — Experimental Protocol (SV4 chủ trì)

Thiết kế để mọi so sánh baseline vs cải tiến là **công bằng, cùng điều kiện**:

* Cùng dataset split + seed với baseline W5.
* Cùng metric: EM / VQA-Acc / ANLS.
* Cùng hardware (hoặc ghi rõ nếu khác).
* Cùng cách normalize answer.
* Định nghĩa trước các cấu hình ablation sẽ chạy (xem W12).
