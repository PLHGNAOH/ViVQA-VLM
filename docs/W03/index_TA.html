Part 02

Research Gap

G1
English-biased Pre-training

VLM alignments are optimized for English — their transferability to Vietnamese has not been thoroughly investigated.

Source: LLaVA-1.5 (Liu 2024) ↗

G2
Weak Vietnamese VQA, especially scene-text

Low performance on ViTextVQA: OCR, Vietnamese diacritics, and code-switching remain unresolved.

Sources: ViTextVQA (Nguyen 2024) ↗ · LLaVA-1.5 (Liu 2024) ↗

G3 — FOCUS
PEFT for Vietnamese VLM remains unexplored

There is no systematic research on applying LoRA/QLoRA to VLMs for Vietnamese VQA — to the best of our knowledge, under-explored.

Evidence: surveyed 3 Vietnamese VQA papers — none applied PEFT/QLoRA (see Literature Matrix).

G4
Hallucination not measured for Vietnamese

There is no hallucination benchmark (POPE-style) evaluated on Vietnamese VQA data — an open direction.

Sources: POPE (Li et al., 2023, EMNLP) · LLaVA-1.5 (Liu 2024) ↗

Part 03

Research Questions

Four research questions guide the entire experimental and ablation analysis.

RQ1
Zero-shot performance on ViVQA/ViTextVQA

How do VLMs perform in a zero-shot setting on the two Vietnamese benchmarks? Evaluated via EM, VQA-Acc, ANLS.

RQ2 — FOCUS
How much does PEFT (QLoRA) improve over zero-shot?

How much improvement does QLoRA yield compared to zero-shot / prompting — without full fine-tuning? This is the central question.

RQ3
OCR-prompting × PEFT on ViTextVQA

Does combining OCR prompting with PEFT create a synergy on ViTextVQA? Evaluated via ANLS.

RQ4
How does PEFT affect hallucination?

Does PEFT increase or decrease hallucination? Evaluated using a POPE-vi style approach.

Part 04

Hypotheses (H1–H8)

Eight verifiable hypotheses — thresholds drawn from international literature, yet to be measured in Vietnamese.

H1 QLoRA achieves ≥ +5 EM/VQA-Acc over zero-shot.
H2 4-bit retains ≥ 97% performance of 16-bit, with VRAM reduction ≥ 40%.
H3 LoRA all-linear outperforms attention-only.
H4 Rank saturates at r ≤ 16 (further increases yield negligible improvement).
H5 Shared adapter ≥ performance of per-dataset adapters.
H6 OCR improves ≥ +3 ANLS, demonstrating synergy with QLoRA.
H7 Vietnamese format-prompt improves ≥ +3 EM.
H8 PEFT does not increase hallucination.

Part 06

Method & Baseline

Prioritized Improvements (PEFT-only)

CORE
QLoRA NF4 all-linear

Quantized LoRA 4-bit, applied to all linear layers — the core method.

PROMPTING
Vietnamese format-prompt

A prompt template specifically designed for Vietnamese to standardize output format.

OCR
OCR-enhanced prompting

Extract text from images using PaddleOCR/VietOCR, passing it to the prompt as additional context.

MULTI-DATASET
Shared adapter

A single adapter shared across multiple datasets — saving parameters and increasing generalization.

OPTIONAL
RAG

Retrieval-Augmented Generation — optional if time permits.

Proposed Baseline

MAIN BASELINE
Qwen2.5-VL-3B-Instruct

Mature tooling, listed in the approved baseline list, runnable on free Colab T4, lower transformers requirement → easier to reproduce.

BACKUP
Florence-2

Backup in case the main baseline encounters VRAM or tooling issues.

Part 11

Core Constraint: PEFT-only

Strictly use LoRA / QLoRA (4-bit / 8-bit).

Reproduce first, improve later

Reproduce exactly one baseline first (W4–W5), then apply improvements.

Same split / seed / hardware

Ensure comparability: same data split, same seed, same hardware for all experiments.

Efficiency as a design constraint

Log VRAM and runtime for each run — efficiency is not a bonus, but a requirement.

Runtime: Google Colab

Free tier for lightweight experiments, Pro for training; mount Google Drive; log GPU each run.
