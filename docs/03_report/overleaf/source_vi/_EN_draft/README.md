# Bản tiếng Anh đã viết sẵn (không được biên dịch)

Các file trong thư mục này là bản tiếng Anh của những phần đã duyệt. Overleaf
không biên dịch thư mục này vì thesis.tex không gọi tới nó.

Khi chuyển sang bản tiếng Anh:
1. File -> Make a copy để tạo project tiếng Anh.
2. Trong Preamble/preamble.tex, đổi \thesisvitrue thành \thesisvifalse.
3. Chép từng file ở đây đè lên file cùng tên ở thư mục gốc.
